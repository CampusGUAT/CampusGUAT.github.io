# 写在前面的话

本站使用 VitePress 进行搭建，VitePress 是一个现代化的静态网站生成器，布局优雅，功能丰富，并且与本站的需求充分契合。关于本站的诞生，有很大运气成分，偶然的机会看到类似于这样的分享以及求生指南等等，源于一时的冲动有这个初稿的诞生，笔者们比不觉得自己能力有多高，能写出这么好的文章。

在本指南出现之前，市面上已经有很多类似的教程。比如交大或者已经存在若干的生存指南和飞跃手册，但是尽管非常全面和完善，但回到自身经历，终归有不一样的地方，有些信息会偏差，因此这就是本站的创建之初。

回想刚到学校的时候，笔者们也和各位一样，对于来到新的学校新的环境十分兴奋，在新生群里面询问各种事宜，抑或是好奇的询问自己感兴趣的社团，同时也伴随着对于前途对于学业对未来的焦虑。

很多时候，大学最大的差距不是天赋，不是努力，而是信息差。不同于高中生主线路线的单一，并且网络上或现实中有大量的有用信息，大学的信息繁杂，但是质量却参差不齐，很容易迷失在其中走在相对错误且浪费时间的道路上，毕业时剩下满脸的后悔，当初为什么不选择另外一条路。

如何在令人目不暇接的丰富大学活动中找到属于自己的路？如何应对课程对时间的消耗？如何学习各类技能的学习与锻炼？如何投入精力打磨竞赛？？如何在学业任务之外，保留属于自己的休闲与娱乐？

一个开源的面向新生的教程指南，旨在降低不同学生之间的信息差，指导大家应该如何更好的在大学中学习生活并提升自我，这便是本教程写作的初衷。

最后，让我们感谢一路走来做出贡献的学长学姐们。
